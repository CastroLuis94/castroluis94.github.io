🚀 PASOS PARA EJECUTAR:

1. Abre una terminal en esta carpeta

2. Instala las dependencias:
   yarn install
   (o: npm install)

3. Ejecuta el proyecto:
   yarn start
   (o: npm start)

4. Abre tu navegador en:
   http://localhost:3000
