# Portfolio Luis Castro

Portfolio profesional de Luis Castro, Machine Learning Engineer especializado en Deep Learning y visión por computadora.

## 🚀 Inicio Rápido

```bash
# 1. Instalar dependencias
yarn install
# o
npm install

# 2. Iniciar servidor de desarrollo
yarn start
# o
npm start
```

La aplicación se abrirá en `http://localhost:3000`

## 📦 Tecnologías

- React 19
- Tailwind CSS
- Shadcn UI
- React Router DOM
- Lucide React (iconos)

## 🎨 Características

- Diseño minimalista y técnico
- Responsive (móvil y desktop)
- Navegación suave con scroll
- Componentes UI modernos
- Formulario de contacto
- Enlaces a redes sociales

## 📝 Personalización

### Actualizar proyectos
Edita `src/components/Projects.jsx` y cambia los links `#` por tus URLs reales.

### Cambiar foto
En `src/components/Hero.jsx`, actualiza la variable `profileImage`.

### Modificar información de contacto
Edita `src/components/Contact.jsx` y `src/components/Footer.jsx`.

## 🏗️ Build para Producción

```bash
yarn build
# o
npm run build
```

Genera la carpeta `/build` lista para desplegar.
